NBA Scoreboard

A live NBA scoreboard driven by an ESP32 MatrixPortal and a 64×32 HUB75 RGB LED matrix. Polls a game-stats API, renders team logos, scores, and clock state on the panel in real time, and syncs its clock over the network. Includes a control server for on-device configuration over mDNS, and a native test harness (with an always-autoplay test server) so display and formatting logic can be exercised without hardware attached.

  • ESP32-S3 (Adafruit MatrixPortal) + Adafruit Protomatter
  • Custom API client: HTTP fetch separated from JSON parsing
  • mDNS-based config & control server, live clock sync
  • Native unit tests via PlatformIO's native environment + ArduinoFake

Rebuilding the NBA scoreboard from scratch on an STM32 Nucleo-F411RE — no WiFi radio, no Protomatter. Driving the HUB75 matrix by hand and talking to an ESP-01 as a dumb WiFi coprocessor over UART AT commands, instead of leaning on HTTPClient.

02 About

I'm moving away from the Arduino/PlatformIO-with-libraries workflow and toward resource-constrained, bare-metal embedded development — direct register access, cross-compiled toolchains, and hardware debugging over SWD/GDB instead of Serial.println. The projects here track that shift: from a fully-featured WiFi scoreboard down to chips with a few kilobytes of RAM and no safety net.
