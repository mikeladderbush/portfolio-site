NBA Scoreboard

Live NBA scoreboard driven by an ESP32 MatrixPortal and a 64×32 HUB75 RGB LED matrix. Game-stats polling, clock synchronization, and the on-device config server each run as independent FreeRTOS tasks rather than a single blocking loop. Display output is handled by Adafruit's Protomatter driver. Display rendering and game-state logic were initially prototyped in CircuitPython, then ported to C++/PlatformIO for the production build.

  • FreeRTOS tasks for polling, clock sync, and the control server
  • ESP32-S3 (Adafruit MatrixPortal) + Adafruit Protomatter for the HUB75 panel
  • Prototyped in CircuitPython, ported to C++ for the real build
  • Custom API client: HTTP fetch separated from JSON parsing
  • mDNS-based config & control server, live clock sync
  • Native unit tests via PlatformIO's native environment + ArduinoFake

Guitar Multitool

        

          Bare-metal guitar practice device on an STM32G031. No HAL, no CMSIS, no RTOS —
          every peripheral register is written by hand from RM0444, including a hand-written
          linker script, vector table, and reset handler, verified on a NUCLEO-G031K8 and
          flashed/debugged over SWD via OpenOCD and GDB.
        

        
    
          
  • Hand-written linker script, vector table, and reset handler — no startup library
    • 
          
  • Register-level GPIO, verified via LMA/VMA inspection of the linked binary
    • 
          
  • Hardware-seeded xorshift32 RNG, seeded from ADC noise on a floating pin
    • 
          
  • Button input with pull-ups, edge detection, and a menu state machine
    • 
          
  • Flash + debug over SWD via OpenOCD/GDB
    • 
          
  • In progress: I2C driver and SSD1306 OLED display output
