Game Tracker 2.0 (NBA / NFL Scoreboard)

Dual-sport scoreboard on an ESP32-S3 MatrixPortal driving a 64×64 HUB75 RGB LED matrix through Adafruit's Protomatter driver. NBA mode shows live score, clock, and period; NFL mode cycles the current week's matchups with spread and over/under. The active sport is switchable at runtime from a browser or the companion Android app, without reflashing. Display and game-state logic were first prototyped in CircuitPython, then ported to C++/PlatformIO.

  • Two FreeRTOS tasks pinned to separate cores: render (core 1, ~60 Hz) and state/network (core 0, ~20 Hz)
  • Sport selection evaluated every loop iteration, enabling live NBA/NFL switching
  • NFL data from ESPN's public endpoint: ~280 KB response with 15-level JSON nesting, parsed via a streaming ArduinoJson filter
  • Custom bitmap font layout using per-glyph ink bounds; 1 px letter gap verified exhaustively across all glyph pairs and sizes
  • HTTP control server with mDNS discovery; companion Android app (Kotlin / Jetpack Compose, NsdManager)
  • 103 native unit tests across 8 suites, plus Flask mock servers with fault injection for offline testing

Active build

        
Guitar Multitool

        

          Bare-metal guitar practice device on an STM32G031. No HAL, no CMSIS, no RTOS —
          every peripheral register is written by hand from RM0444, including a hand-written
          linker script, vector table, and reset handler, verified on a NUCLEO-G031K8 and
          flashed/debugged over SWD via OpenOCD and GDB. Breadboard testing with the target
          OLED and buttons is under way.
        

        
    
          
  • Hand-written linker script, vector table, and reset handler — no startup library
    • 
          
  • Register-level GPIO, verified via LMA/VMA inspection of the linked binary
    • 
          
  • I2C1 on PB6/PB9 (open-drain, AF6) with 100 kHz timing derived from the 16 MHz HSI clock
    • 
          
  • SSD1306 initialization over I2C, including the charge-pump enable sequence; display response confirmed on breadboard
    • 
          
  • ADC-noise-seeded xorshift32 RNG for randomized note generation
    • 
          
  • Three-button input with pull-ups, edge detection, and a menu state machine
    • 
          
  • In progress: frame buffer flush, font rendering, practice-mode logic
    •
